Backup e restauração

Exporte todos os dados do sistema em formato JSON para fazer um backup, ou importe um arquivo de backup para restaurar os dados. A importação valida o arquivo antes de substituir qualquer dado existente.

As funções de exportação e importação de dados serão implementadas na Etapa 08.

Exportar dados

Gera um arquivo techtrack-backup.json com todos os dados atuais do sistema.

Importar dados

Selecione um arquivo de backup gerado pelo TechTrack. O sistema validará o arquivo antes de qualquer alteração. Os dados atuais serão preservados caso o arquivo seja inválido.
